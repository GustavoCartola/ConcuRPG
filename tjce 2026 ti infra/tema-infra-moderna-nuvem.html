Tema 4: Infra Moderna + Nuvem

Foco FCC: operacao real, nao so teoria.

  • Container compartilha kernel do host.
  • VM inclui SO completo e maior isolamento.
  • Docker: imagem, container, volume, rede.
  • Bridge e padrao; host/none para casos especificos.
  • Frase: VM isola mais, container entrega mais rapido.
  • Kubernetes orquestra containers.
  • Escalabilidade, self-healing e deploy controlado.
  • Pods, nodes, servicos e afinidade sao pontos classicos.
  • Rancher ajuda gestao de clusters.
  • CI/CD: build, teste, scan, deploy.
  • GitLab CI: runner + .gitlab-ci.yml.
  • Pipeline boa reduz erro manual e acelera entrega.
  • DevSecOps: seguranca integrada no pipeline.
  • Nuvem: IaaS, PaaS, SaaS.
  • Publica, privada e hibrida.
  • AWS/Azure: IAM, MFA, WAF, logs, segmentacao.
  • HA em nuvem: balanceador + auto scaling + arquitetura resiliente.
  • Dockerfile: EXPOSE documenta porta da aplicacao.
  • docker history mostra camadas da imagem.
  • Volumes persistem dados fora do ciclo de vida do container.
  • docker run -d executa em background.
  • Bridge e rede default na maioria dos cenarios.
  • Kubernetes: declarativo com kubectl apply.
  • Imperativo com create para acoes pontuais.
  • GitLab CI passos iniciais: runner + arquivo pipeline.
  • Cluster HA: ativo-passivo (reserva), ativo-ativo (distribui carga).
  • Frase: orquestracao boa reduz indisponibilidade.
