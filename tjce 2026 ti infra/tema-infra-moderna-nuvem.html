Tema 4: Infra Moderna + Nuvem

Foco FCC: operacao real, nao so teoria.

  • Container = kernel compartilhado.
  • VM = SO completo.
  • Docker = criacao e execucao de containers.
  • Bridge = rede padrao.
  • Imagem Docker = imutavel.
  • Containers = mais leves que maquinas virtuais.
  • Maior isolamento = pense em VM.
  • NFV = funcoes de rede em software.
  • Nuvem = IaaS, PaaS e SaaS.
  • Modelos = publica, privada e hibrida.
  • AWS/Azure = IAM, MFA e WAF.
  • HA = balanceador + auto scaling.
  • Kubernetes = orquestracao.
  • Kubernetes = escala e self-healing.
  • Elementos = pods, nodes e services.
  • Rancher = gestao de clusters.
  • IaC = infraestrutura como codigo.
  • Ansible = automacao.
  • Provisionamento = execucao automatizada.
  • SDI = infraestrutura definida por software.
  • EXPOSE = define porta.
  • docker history = mostra camadas.
  • Volume = persistencia.
  • -d = execucao em background.
  • kubectl apply = declarativo.
  • kubectl create = imperativo.
  • Kubernetes = orquestra workloads.
  • HA = ativo-passivo ou ativo-ativo.
