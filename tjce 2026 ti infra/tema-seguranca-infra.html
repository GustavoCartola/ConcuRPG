Tema 1: Seguranca de Infra

Foco FCC: conceito aplicado + decisao de arquitetura.

  • Firewall = filtra trafego.
  • WAF = protege HTTP/HTTPS.
  • IDS = detecta; IPS = detecta e bloqueia.
  • SIEM = correlacao de eventos.
  • IAM = gestao de identidades.
  • RBAC = permissao por papel.
  • MFA = autenticacao em 2 fatores.
  • SSO = login unico.
  • CIA = confidencialidade, integridade e disponibilidade.
  • Hash = integridade.
  • AES = simetrica; 3DES = legado.
  • RSA = assimetrica.
  • Trojan = programa disfarcado.
  • Worm = propagacao automatica.
  • Virus = precisa de hospedeiro.
  • Worm se replica; virus depende de arquivo hospedeiro.
  • Worm pode enviar e-mails automaticamente para toda a lista de contatos, sem ação do usuário.
  • Worm = propagação automática, inclusive por e-mail.
  • Virus de boot = infecta setor de inicializacao do disco.
  • Virus mutante = altera o proprio codigo para dificultar deteccao.
  • Virus de script = embutido em scripts; age ao executar o arquivo.
  • Boot = inicializacao; mutante = evasao; script = execucao.
  • Antivirus: monitora.
  • Quarentena: isola.
  • Atualizacao: protege mais.
  • I e III ok; II exagera.
  • Teste de intrusao = ataque controlado.
  • Malware = artefato e comportamento malicioso.
  • VPN = IPsec, SSL VPN ou IKEv2.
  • Seguranca = tecnologia + processo + usuario.
  • Hardening de e-mail = SPF, DKIM e DMARC.
  • Incidente = impacto baixo, medio ou alto.
  • SIEM = coleta, correlaciona e alerta.
  • Cifra protege; hash garante.
  • IDS: detecta.
  • Firewall filtra por regra.
  • Firewall bloqueia.
  • IDS monitora.
  • Firewall: borda.
  • Borda + regra = firewall.
  • Proxy intermedia.
  • Regra de borda.
  • Stateful = acompanha conexoes TCP.
  • Stateful considera estado da sessao.
  • Stateless = avalia pacote isolado.
  • Fluxo e sessao = stateful.
  • Tipos de firewall = proxy, inspecao de estado (stateful), UTM e NGFW.
  • Firewall de proxy = intermedia requisicoes e inspeciona camada de aplicacao.
  • UTM = firewall + antivirus + IDS/IPS + VPN em um unico appliance.
  • NGFW = UTM + inspecao profunda de pacotes (DPI) + controle de app.
  • Todos os quatro sao tipos reconhecidos de firewall.
  • Firewall dedicado (appliance) = equipamento próprio para filtrar tráfego, com mais performance e segurança.
  • Firewall pode ser software ou hardware dedicado.
  • Spyware = espionagem.
  • Adware e Keylogger = tipos de spyware.
  • Ransomware = sequestro de dados.
  • Browser Hijacker = altera homepage.
  • Spyware = coleta informações pessoais, exibe publicidade e pode alterar configurações sem consentimento.
  • Adware = publicidade; Keylogger = captura teclas; Browser Hijacker = altera navegador.
  • Ransomware compromete disponibilidade (bloqueia acesso aos dados).
  • Prevenção é a estratégia primordial contra ransomware.
  • Backup, atualização e cautela com anexos = prevenção.
  • Recuperação só é útil se a prevenção falhar.
  • RAT = trojan de acesso remoto.
  • Backdoor = porta de acesso oculto.
  • Botnet = rede de maquinas zumbis.
  • Acesso remoto como usuario = pense em RAT.
  • Pharming = redireciona para site falso.
  • Explora browser, SO ou DNS.
  • Phishing = engana por mensagem/link.
  • Redirecionamento tecnico para pagina bancaria falsa = Pharming.
  • Rootkit = conjunto para manter acesso privilegiado oculto.
  • Root = controle total do sistema.
  • Keylogger = captura digitacao.
  • Nivel raiz + ferramentas de ocultacao = Rootkit.
  • Software Bomb = bomba logica.
  • Disparo = ocorre apos evento ou condicao.
  • Nao costuma mostrar sintoma antes da ativacao.
  • Evento marcado + acao destrutiva = Software Bomb.
  • Hoax = mensagem falsa com aparencia de verdade.
  • Objetivo = persuadir usuario a agir.
  • Nao depende de exploracao tecnica no host.
  • Se fala em convencer leitor por mensagem = Hoax.
  • Malware = software malicioso (virus, worm, trojan, spyware).
  • Phishing = fraude por mensagem, link ou pagina falsa.
  • Spam = mensagem indesejada em e-mail e outros meios.
  • Firewall + antivirus = reduz risco, mas nao elimina incidentes.
  • Firewall não é antivírus: firewall filtra tráfego, antivírus detecta malware.
  • Firewall = bloqueia conexões; antivírus = analisa arquivos.
  • Antispam pode falhar se o e-mail estiver em idioma diferente.
  • Phishing = e-mail pode conter link malicioso.
  • Antivírus com heurística = detecta ameaças novas, é confiável.
  • Heurística = identifica comportamento suspeito, não só assinatura.
  • Zero-day = ameaca nova sem assinatura conhecida.
  • Antivirus por assinatura = pode falhar em variante inedita.
  • Analise comportamental = detecta anomalia de execucao.
  • Cryptojacking = uso indevido de CPU para mineracao.
  • Scareware = falso alerta para assustar usuario.
  • Spyware, Ransomware e Worm = familias de malware.
  • Cryptojacking = pratica de mineracao maliciosa.
  • Se a banca pedir o que nao e familia classica de malware, pode marcar Cryptojacking.
  • MitM = intercepta comunicacao entre duas partes sem que percebam.
  • Ataque de aniversario = explora colisao de hash (duas entradas com mesmo hash).
  • MitM = espionagem ativa; Ataque de aniversario = criptografia/hash.
  • XSS = injeta script no navegador da vitima (nao e instalacao de software).
  • DDoS = sobrecarga de servico por multiplas origens.
  • RBAC nao e exclusivo Microsoft.
  • MFA: sabe, tem, e.
  • LGPD: titular + governanca.
  • Cifra protege; hash confere.
