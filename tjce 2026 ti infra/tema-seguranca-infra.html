Tema 1: Seguranca de Infra

Foco FCC: conceito aplicado + decisao de arquitetura.

  • Firewall = filtra trafego.
  • WAF = protege HTTP/HTTPS.
  • IDS = detecta; IPS = detecta e bloqueia.
  • SIEM = correlacao de eventos.
  • IAM = gestao de identidades.
  • RBAC = permissao por papel.
  • MFA = autenticacao em 2 fatores.
  • SSO = login unico.
  • CIA = confidencialidade, integridade e disponibilidade.
  • Hash = integridade.
  • AES = simetrica; 3DES = legado.
  • RSA = assimetrica.
  • Trojan = programa disfarcado.
  • Worm = propagacao automatica.
  • Virus = precisa de hospedeiro.
  • Worm se replica; virus depende de arquivo hospedeiro.
  • Antivirus: monitora.
  • Quarentena: isola.
  • Atualizacao: protege mais.
  • I e III ok; II exagera.
  • Teste de intrusao = ataque controlado.
  • Malware = artefato e comportamento malicioso.
  • VPN = IPsec, SSL VPN ou IKEv2.
  • Seguranca = tecnologia + processo + usuario.
  • Hardening de e-mail = SPF, DKIM e DMARC.
  • Incidente = impacto baixo, medio ou alto.
  • SIEM = coleta, correlaciona e alerta.
  • Cifra protege; hash garante.
  • IDS: detecta.
  • Firewall filtra por regra.
  • Firewall bloqueia.
  • IDS monitora.
  • Firewall: borda.
  • Borda + regra = firewall.
  • Proxy intermedia.
  • Regra de borda.
  • Stateful = acompanha conexoes TCP.
  • Stateful considera estado da sessao.
  • Stateless = avalia pacote isolado.
  • Fluxo e sessao = stateful.
  • Spyware: espionagem.
  • Adware: propaganda indesejada.
  • Ransomware: sequestro de dados.
  • Browser Hijacker: altera homepage.
  • RAT = trojan de acesso remoto.
  • Backdoor = porta de acesso oculto.
  • Botnet = rede de maquinas zumbis.
  • Acesso remoto como usuario = pense em RAT.
  • Pharming = redireciona para site falso.
  • Explora browser, SO ou DNS.
  • Phishing = engana por mensagem/link.
  • Redirecionamento tecnico para pagina bancaria falsa = Pharming.
  • Rootkit = conjunto para manter acesso privilegiado oculto.
  • Root = controle total do sistema.
  • Keylogger = captura digitacao.
  • Nivel raiz + ferramentas de ocultacao = Rootkit.
  • Hoax = mensagem falsa com aparencia de verdade.
  • Objetivo = persuadir usuario a agir.
  • Nao depende de exploracao tecnica no host.
  • Se fala em convencer leitor por mensagem = Hoax.
  • RBAC nao e exclusivo Microsoft.
  • MFA: sabe, tem, e.
  • LGPD: titular + governanca.
  • Cifra protege; hash confere.
