Tema 2: Redes

Foco FCC: dominio conceitual + precisao de protocolo/padrao.

  • OSI = modelo de 7 camadas.
  • TCP/IP = modelo de 4 camadas.
  • TCP = confiavel; UDP = leve.
  • ARP = IP/MAC; ICMP = ping.
  • Smurf = ataque com ping para broadcast.
  • Respostas sao refletidas para a vitima.
  • ICMP + broadcast = amplificacao de DoS.
  • Ping em massa para broadcast com alvo terceiro = Smurf.
  • IPv4 = 32 bits.
  • IPv6 = 128 bits.
  • CIDR = prefixo.
  • VLAN 802.1Q = segmentacao com trunk.
  • DHCP = entrega IP.
  • DNS = resolve nomes.
  • SNMP = monitoracao.
  • NAT/PAT = traducao de enderecos.
  • RIP, OSPF, BGP = roteamento.
  • STP/RSTP = evita loop.
  • VPN = tunel seguro.
  • QoS = controla latencia, jitter e perda.
  • Cabos = par, coaxial e fibra.
  • QoS = priorizacao de trafego.
  • Fisica = meio guiado e nao guiado.
  • OSPF = rota por custo.
  • 802.11 = WLAN.
  • Roteador = encaminha pacote IP.
  • Flow label = fluxo.
  • DNS = pode balancear acesso.
