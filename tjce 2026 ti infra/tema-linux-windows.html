Tema 3: Linux / Windows

Foco FCC: comandos e administracao pratica de servico.

  • AD DS = dominio.
  • LDAP = diretorio.
  • RBAC + GPO = permissao centralizada.
  • Grupo = forma pratica de aplicar permissao.
  • SSH = acesso remoto seguro.
  • SCP = copia via SSH.
  • ssh-keygen = gera chave.
  • Teste = evita queda apos recarregar servico.
  • ls, cp, mv, rm = operacoes basicas.
  • chmod, chown, chgrp = controle de permissao.
  • 755 e 644 = padroes comuns.
  • find e grep = busca.
  • iptables = cadeia, regra e acao.
  • UFW = frontend do firewall.
  • SELinux permissive = registra sem bloquear.
  • LVM = PV, VG e LV.
  • ps, awk, vmstat, top, systemctl = administracao diaria.
  • Zumbi = processo em estado Z.
  • Thrashing = swap alto com perda de desempenho.
  • Logs e processos = base de diagnostico.
  • Instalar, habilitar e validar = fluxo minimo.
  • Monitorar servico = evitar parada silenciosa.
  • SCP = origem:destino.
  • Sem log = sem diagnostico.
